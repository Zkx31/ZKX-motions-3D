# Livraison ZKX Digital Lab

## Nouvelle publicité verticale — Vos véritables sites

- [Vidéo MP4 verticale](ZKX-Portfolio-Vertical-35s.mp4)
- [Projet Remotion modifiable et médias](ZKX-Portfolio-Vertical-Source.zip)
- [Aperçu des scènes du MP4 final](APERCU-Vertical.jpg)

35 secondes de vidéo, 1080×1920, 30 images/s (1050 images), codec H.264, audio AAC stéréo. Le fichier a été entièrement décodé sans erreur et préparé pour la lecture rapide (fast-start).

Les véritables interfaces de ZKX Digital Lab, ETP Peinture, B.K Multiservices et Nero Toulouse proviennent des quatre enregistrements mobiles fournis. Les éléments de navigateur et d’interface système ont été recadrés, sans déformation des sites. Les trois projets sont présentés comme des extraits du portfolio. La bande-son est originale ; le son des enregistrements n’est pas repris.

Pour télécharger : ouvrez le MP4 ou l’archive, puis cliquez sur l’icône de téléchargement « Download raw file » de GitHub. Ouvrez le MP4 avec votre lecteur habituel si GitHub ne propose pas de lecteur intégré.

Le projet inclut les extraits préparés, les dépendances verrouillées, les scripts et la documentation `VERTICAL.md`. Les titres sont calculés en 1080×1920 ; le calque 3D utilise un tampon de 720×1280 pour le rendu logiciel. Les enregistrements d’origine ont une largeur de 512 pixels. Aucune visite directe des sites par Playwright n’est revendiquée : le proxy bloquait leurs domaines et les enregistrements fournis ont servi de source.
